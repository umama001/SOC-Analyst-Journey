# 🛡️ SOC Analyst Role Overview (Foundation)

## Objective
Understand the structure, responsibilities, and tools used in a Security Operations Center (SOC) to support real-world security monitoring and incident response.

## SOC Structure
A Security Operations Center (SOC) is responsible for continuous monitoring, detection, and response to security threats across systems and networks.
  
## Key Roles:
- L1 Analyst (Tier 1)
  - Monitors alerts from SIEM tools  
  - Performs initial triage  
  - Escalates confirmed threats  

- L2 Analyst (Tier 2)
  - Conducts deep investigation  
  - Handles complex incidents  

- SOC Engineer
  - Configures tools like Splunk and EDR  
  - Maintains detection rules  

- SOC Manager
  - Oversees operations and team performance  

- Incident Responder
  - Handles major breaches and containment

## Core Responsibilities of L1 Analyst
- Monitors security alerts from SIEM  
- Analyzes suspicious activity  
- Identifies potential threats  
- Escalates confirmed incidents  
- Documents findings in incident reports  

## Key Tools Used
- SIEM Platforms (e.g., Splunk)  
- Network Analysis Tools (e.g., Wireshark)  
- Endpoint Detection & Response (EDR)  
- Threat Intelligence Platforms
